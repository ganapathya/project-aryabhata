# Project Aryabhata

A personal, gamified system for learning mathematics until it sits at the fingertips: calculus first, then proofs and linear algebra, then a physics branch (differential equations through thermodynamics and fluids) and a structure-and-information branch (probability, information theory, topology, TDA and category theory).

Named after Aryabhata (476–550 CE), the mathematician-astronomer of classical India.

## How it teaches

Every idea passes through four stages: **see it** (a picture or a physical question), **derive it** (by hand, with scaffolding that fades), **build it** (a small simulation in Python, predicted before it runs), and **keep it** (spaced review that lets skills go rusty if unused). A Socratic tutor asks rather than tells, and a symbolic maths engine, not the tutor, decides whether each step is right.

Open the repo in Claude Code and ask for an agent by name, for example:

- "Use the architect to write the decision records and interfaces for M0."
- "Have the professor draft Module 1."
- "Ask the engineer to run spike 1."
- "Get the systems-tester to gate M1."
